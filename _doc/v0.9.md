# Code5 v0.9 更新日誌

## 版本資訊

- 版本: 0.9 (2026-05-07)
- 日期: 2026-05-07
- 主要功能: Web 版支援 CLI 指令

## 概述

在 Web 版中加入原本 CLI 版支援的指令，讓使用者可以在網頁版使用 `/shell`、`/history`、`/log`、 `/agent` 等指令。

## 功能實作

### 1. 支援的指令

| 指令 | 說明 | 狀態 |
|------|------|------|
| `/shell <cmd>` | 執行 shell 命令 | ✓ |
| `/history <n>` | 查看前 n 筆提問 | ✓ |
| `/log <n>` | 查看前 n 筆記錄 | ✓ |
| `/agent list` | 列出所有 agent | ✓ |
| `/agent new <name>` | 建立新 agent | ✓ |
| `/agent attach <name>` | 切換 agent | ✓ |
| `/agent history` | 顯示 agent 提問 | ✓ |
| `/agent log` | 顯示 agent 記錄 | ✓ |
| `/help` | 顯示說明 | ✓ |

### 2. 技術實作

- 建立 `code5/web/commands.py` 模組
- WebAgentStore 儲存 agent 資料（in-memory）
- 指令解析與執行完全獨立於 CLI
- 與現有 SessionStore 相容

### 3. API 端點

現有 `/api/chat` 自動偵測指令：
- 以 `/` 開頭的訊息視為指令
- 指令執行結果以 Markdown 格式回傳

## 檔案異動

### 新增檔案

- `src/code5/web/commands.py` - 指令模組（指令解析、執行、管理）

### 修改檔案

- `src/code5/web/routes.py` - 整合指令處理到 chat 端點
- `tests/test_web.py` - 新增 TestWebCommands 測試

## 使用方式

在網頁輸入框輸入指令即可：
```
/shell ls -la
/history 5
/log 10
/agent list
/agent new myagent
/agent attach myagent
/help
```

## 行為變更

1. Web 支援 CLI 指令（與 CLI 版功能相同）
2. 指令執行結果會儲存到 agent history
3. `/shell` 指令可直接執行 shell 命令
