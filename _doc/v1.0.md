# Code5 v1.0 規劃

## 版本資訊

- 版本: 1.0 (已完成)
- 日期: 2026-05-07
- 主要功能: Web 版完整 CLI 指令 + Session 選擇介面

## 概述

1. 補齊 CLI 指令（/list, /attach, /new, /now 等）
2. 改進入口：先顯示 Session 選擇畫面，再進入對話

## 功能需求

### 1. 補齊的指令

| 指令 | 說明 | Web 版實作位置 |
|------|------|---------------|
| `/list` | 列出所有 sessions | `web/commands.py:260` |
| `/new <name>` | 建立新 session | `web/commands.py:271` |
| `/attach <name>` | 切換到其他 session | `web/commands.py:278` |
| `/now` | 顯示目前 session/agent | `web/commands.py` |
| `/exit` | 結束對話 | - |
| `/history <n>` | 查看前 n 筆提問 | `web/commands.py:104` |
| `/log <n>` | 查看前 n 筆記錄 | `web/commands.py:117` |

### 2. Session 選擇畫面

- 進到首頁時顯示「選擇 Session」畫面 (`/sessions`)
- 可選擇現有 session 或建立新 session
- 選擇後進入聊天室 (`/chat?session=xxx`)
- Session 資料持久化到 JSON 檔案

### 3. 前端改進

- Session 選擇頁面 (`templates/session.html`)
- 顯示目前所在的 session
- Markdown 渲染優化：支援 `###中文` 不帶空格的標題語法
- 指令輸出格式：使用 `【】` 取代 `===`，避免被視為 markdown 標題

## 技術設計

### 指令實作

在 `web/commands.py` 中：
- `execute_history(n, session_history)` - 使用 session history
- `execute_log(n, session_history)` - 使用 session history
- `execute_list()` - 列出所有 sessions
- `execute_new(name)` - 建立新 session
- `execute_attach(name)` - 切換 session
- `execute_now()` - 顯示目前狀態

### 前端頁面

- `templates/session.html` - Session 選擇頁面
- 修改 `index.html` - 加入 markdown 修復和 session 顯示
