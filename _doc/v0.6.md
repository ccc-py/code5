## 概述

## Bug 修復

### /bg stdout/stderr 污染問題

**問題**：`/bg` 使用 `os.dup` 將 stdout/stderr 導入 `/dev/null`，造成全域 fd 被污染，導致後續指令輸出異常。

**原因**：
```python
# 舊程式碼使用 os.dup 全域替換
os.dup2(devnull, 1)  # 影響全域 stdout
os.dup2(devnull, 2)  # 影響全域 stderr
```

**解決方案**：改用 `StringIO` 局部替換，不影響全域 fd。
```python
from io import StringIO
output_buffer = StringIO()

async def run_bg():
    old_stdout = sys.stdout
    old_stderr = sys.stderr
    try:
        sys.stdout = output_buffer
        sys.stderr = output_buffer
        await current_agent[0].run(prompt)
    finally:
        sys.stdout = old_stdout
        sys.stderr = old_stderr
        output = output_buffer.getvalue()
        if output:
            print(f"[背景任務 #{task_id} 輸出]\n{output}")
```

### 指令未寫入 history

**問題**：系統指令 (`/help`, `/history`, `/log` 等) 執行後不會寫入歷史記錄。

**解決方案**：將 `memory.update` 移入 `handle_command` 內部，所有指令都會自動寫入。

```python
def handle_command(user_input: str, ...):
    current_agent[0].memory.update(user_input, "", None)  # 加入這行
    cmd = user_input.lower()
    # ... 處理指令
```

|------|------|
| `test_bg_then_history` | /bg 後執行 /history 正常（包含 `/bg` 指令） |
| `test_bg_then_log` | /bg 後執行 /log 正常 |
| `test_bg_then_now` | /bg 後執行 /now 正常 |
| `test_bg_then_list` | /bg 後執行 /list 正常 |
| `test_bg_then_help` | /bg 後執行 /help 正常 |
| `test_bg_stdout_restored` | 確認 stdout 已恢復，不影響全域輸出 |
| `test_command_added_to_history` | 確認 `/list`, `/now`, `/help` 等指令會寫入 history |
