- 版本: 0.4 (規劃中)

- 主要更新: Agent 管理

## 概述

在 Session 內加入 Agent 概念，允许在一个 Session 中创建多个不同的 Agent（子对话上下文）。

## 概念

- **Session** - 对话区块，通过 `-n` 指定
- **Agent** - Session 内的子对话上下文，有自己的名称和设定
- 不同的 Session 就算 Agent 名称相同，也是不同的 Agent
- 默认的 Agent 名称是 `root`

## 指令

### `/agent new <name>`

创建新的 Agent：

```
/agent new mybot
# 或
agent new mybot
```

效果：
- 在当前 Session 中创建名为 `<name>` 的新 Agent
- 之後的指令都會傳給該 Agent
- Agent 的設定會記錄在 Session 中

### `/agent list`

列出所有 Agent：

```
/agent list
```

輸出：
```
=== Agents ===
  root (系統預設)
  mybot (建立於: 2026-05-05 17:00)
```

### `/agent attach <name>`

切換到其他 Agent：

```
/agent attach otherbot
# 或
agent attach otherbot
```

效果：
- 切換到該 Agent，繼續對話
- 之前的對話記錄會保留

### `/agent now`

顯示目前 Agent：

```
/agent now
```

輸出：
```
目前 agent: mybot
```

### `/agent history`

顯示與該 Agent 的對話歷史（提問）：

```
/agent history
```

輸出：
```
=== mybot 對話歷史 ===
1. 帮我写一个 HTTP server
2. 再加上路由功能
```

### `/agent log`

顯示與該 Agent 的完整對話記錄：

```
/agent log
```

輸出：
```
=== mybot 完整對話記錄 ---
[你] 帮我写一个 HTTP server
[AI] 已创建 HTTP server...
[你] 再加上路由功能
[AI] 已添加路由...
```

### 其他對話指令（保持不變）

- `/session list` - 列出所有 session
- `/session now` - 顯示目前 session
- `/history` - 顯示所有提問（當前 session + 當前 agent）
- `/log` - 顯示完整記錄（當前 session + 當前 agent）
- `/exit` - 結束

## 資料儲存

### SQLite 結構

```sql
-- conversations table 新增 agent_id 欄位
CREATE TABLE conversations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id TEXT NOT NULL,
    agent_id TEXT NOT NULL,
    role TEXT NOT NULL,
    content TEXT NOT NULL,
    created_at TEXT NOT NULL
);

-- agents table - 記錄每個 agent 的設定
CREATE TABLE agents (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id TEXT NOT NULL,
    agent_id TEXT NOT NULL,
    name TEXT NOT NULL,
    system_prompt TEXT,
    created_at TEXT NOT NULL
);
```

### 查詢

- `/log` - 目前 session + 目前 agent 的記錄
- `/history` - 目前 session + 目前 agent 的提問
- `/agent log` - 目前 agent 的完整記錄
- `/agent history` - 目前 agent 的提問
- `code5 session list` - 列出所有 session
- `code5 session list` + `/agent list` - 完整歷史

## 使用範例

```
# 1. 開始新專案
code5 run -n myproject
> /agent new webbot
> 帮我写一个 HTTP server

> /agent new clibot

> /agent attach webbot
> 再加上路由功能

> /agent now
目前 agent: webbot
```

## 預期行為

- 不同 Agent 有獨立的對話上下文
- 對話歷史會記錄 Agent 名稱
- 可以隨時切換 Agent
- Session 切換時，Agent 會重置為 root
