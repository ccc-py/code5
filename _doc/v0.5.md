# Code5 v0.5 功能規劃

## 版本資訊

- 版本: 0.5 (規劃中)
- 日期: 2026-05-05
- 主要更新: 批次指令執行 + Session 掛載

## 概述

支援在 heredoc 中執行多行指令，包括 AI prompt 和系統指令。可以一次完成建立 agent、執行工作、查看記錄等流程。

## 指令用法

### 基本用法

```bash
# 單次執行 (新 session)
code5 /new myproject <<EOF
幫我寫一個 hello.py
EOF

# 批次執行 (指定 session) - 標準 heredoc 語法
code5 /attach mysession <<EOF
幫我寫一個 hello.py
/agent new webbot
/agent log
EOF

# 互動模式 (新 session)
code5 /new myproject

# 互動模式 (繼續 session)
code5 /attach myproject
```

### Session 管理 (CLI)

```bash
code5 /version                 # 顯示版本
code5 /help                    # 顯示幫助
code5 /session list           # 列出所有 session
code5 /doctor                # 診斷設定
```

### 互動模式指令

```bash
/help              - 顯示這說明
/history           - 顯示目前 agent 提問
/log               - 顯示目前 agent 完整記錄
/shell <cmd>       - 執行 shell 命令
/session list     - 列出所有 session
/session new <name> - 切換到新 session
/session attach <name> - 切換到其他 session
/agent list        - 列出目前 session 的所有 agent
/agent now         - 顯示目前 agent
/agent new <name> - 建立新 agent
/agent attach <name> - 切換到其他 agent
/agent history    - 顯示該 agent 提問
/agent log         - 顯示該 agent 完整記錄
/exit              - 結束對話
```

## 批次指令 (heredoc / pipe)

Heredoc 中可以混合 AI prompt 和系統指令，按行執行。

### 語法

```bash
# 方式一：heredoc
code5 /attach myproject <<EOF
/agent new webbot
幫我寫一個 HTTP server
/shell python server.py &
/agent log
EOF

# 方式二：pipe
cat myscript.txt | code5 /attach myproject
```

### 指令類型

| 指令 | 說明 |
|------|------|
| AI prompt | 傳給 AI 處理 |
| `/xxx` 開頭 | 系統指令，見互動模式指令表 |

### 執行順序

1. 由上而下依序執行
2. AI prompt → 呼叫 AI，返回結果
3. 系統指令 → 執行指令，回傳輸出
4. 所有結果依序輸出

### 輸入來源

```bash
# 方式一：heredoc
code5 /attach myproject <<EOF
/agent new webbot
幫我寫一個 HTTP server
EOF

# 方式二：pipe
cat myscript.txt | code5 /attach myproject

# 方式三：echo
echo "幫我寫一個 hello.py" | code5 /new myproject
```

## 使用範例

### 範例一：建立 agent + 執行工作

```bash
code5 /attach myproject <<EOF
/agent new webbot
幫我寫一個 HTTP server
EOF
```

執行流程：
1. `/agent new webbot` → 建立 webbot agent
2. `幫我寫一個 HTTP server` → AI 執行，返回代码

### 範例二：多個工作 + 查詢結果

```bash
code5 /attach myproject <<EOF
幫我寫一個 HTTP server
/shell python server.py &
/agent log
EOF
```

執行流程：
1. `幫我寫一個 HTTP server` → AI 返回代码
2. `/shell python server.py &` → 執行服务器
3. `/agent log` → 顯示對話記錄

### 範例三：建立 + 使用 + 切換 agent

```bash
code5 /attach projectA <<EOF
/agent new webbot
幫我寫一個 HTTP server

/agent new apibot
幫我寫一個 REST API

/agent attach webbot
幫我加上 HTTPS 支援
EOF
```

### 範例四：完整工作流

```bash
code5 /attach myproject <<EOF
/agent list
/agent new mybot
幫我寫一個 TODO list 應用
/shell ls -la
/agent log
EOF
```

### 範例五：多環境切換

```bash
# A 專案 (新 session)
code5 /new projectA <<EOF
幫我寫一個登入功能
EOF

# B 專案 (新 session)
code5 /new projectB <<EOF
幫我寫一個購物車功能
EOF

# 之後繼續執行
code5 /attach projectA <<EOF
新增密碼重設功能
EOF

code5 /attach projectB <<EOF
新增優惠碼功能
EOF
```

## 工作流程

### 流程一：單次執行（新 Session）

```bash
# 單次執行 (新 session)
code5 /new myproject <<EOF
幫我寫一個 hello.py
EOF
```

### 流程二：單次執行（指定 Session）

```bash
# 先查看有哪些 session
code5 /session list

# 在指定 session 中執行 heredoc
code5 /attach myproject <<EOF
幫我新增一個路由
/shell ls src/
/agent log
EOF
```

### 流程三：互動模式

```bash
# 進入互動模式 (新 session)
code5 /new myproject

# 進入互動模式 (繼續 session)
code5 /attach myproject
```

## CLI 指令

```bash
code5 /new <name> <<EOF              # 新 session + 執行
EOF

code5 /attach <name> <<EOF           # 指定 session + 執行
EOF
cat script.txt | code5 /attach <name>   # pipe 輸入

code5 /new <name>                    # 新 session，進入互動
code5 /attach <name>               # 繼續 session，進入互動

code5 /version                     # 顯示版本
code5 /help                        # 顯示幫助
code5 /doctor                     # 診斷設定
code5 /session list               # 列出所有 session
```

## 環境變數

- `NVIDIA_API_KEY` - NVIDIA NIM API key
- `NVIDIA_MODEL` - 模型名稱（預設: minimaxai/minimax-m2.7）
- `NVIDIA_BASE_URL` - API 端點
- `CODE5_USE_MOCK` - 設為 `true` 使用 mock 模式

## 資料儲存

- SQLite: `~/.code5/code5.db`
- Session: 對話區塊
- Agent: Session 內的子對話上下文
- root: 預設 Agent 名稱

## 預期行為

1. heredoc 中可以混合 AI prompt 和系統指令
2. 系統指令包含：/agent, /session, /shell, /log, /history 等
3. 由上而下依序執行，回傳結果
4. 對話記錄會保存在 SQLite 中
5. 可以一次完成建立、執行、查詢的完整流程
