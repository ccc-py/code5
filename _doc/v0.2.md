## 目標

簡化設計：
- 一個命令列（輸入區）
- 合併的面板（顯示對話 + 輸出）

```
┌─────────────────────────────────────────┐
│ 合併面板 (Output + Conversation)        │
│ $ cat hello.py                         │
│ print("Hello, World!")                 │
│                                         │
│ <user> 寫一個 hello.py                  │
│ <assistant> 已建立 hello.py            │
│                                         │
├─────────────────────────────────────────┤
│ 命令列 >                                │
└─────────────────────────────────────────┘
```

## 技術選型

**urwid** - 輕量級 TUI 框架

優點：
- 簡單易用
- 支援顏色
- 跨平台
- 非同步更新

## 功能

1. **合併面板**
   - 顯示使用者輸入
   - 顯示 AI 回覆
   - 顯示 shell 執行結果
   - 自動滾動

2. **命令列**
   - 單行輸入
   - 鍵盤歷史（上下鍵）

3. **鍵盤快捷鍵**
   - `Ctrl+L`: 清屏
   - `Ctrl+C`: 取消
   - `Up/Down`: 命令歷史

4. **顏色輸出**
   - 警告：黃色
   - 錯誤：紅色
   - 資訊：綠色

## API 設計

```bash
# 啟動美化模式
code5

# 或

```
