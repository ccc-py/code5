# Code5 v0.8 更新日誌

## 版本資訊

- 版本: 0.8 (2026-05-07)
- 日期: 2026-05-07
- 主要功能: FastAPI Web 介面

## 概述

新增 FastAPI 網站版介面，提供網頁版對話功能，支援即時串流回應、對話歷史、session 管理。

## 功能實作

### 1. Web API 端點

| 端點 | 方法 | 說明 |
|------|------|------|
| `/` | GET | 首頁（網頁聊天室） |
| `/api/chat` | POST | 發送訊息 |
| `/api/chat/stream` | POST | 串流發送訊息 |
| `/api/sessions` | GET | 列出所有 sessions |
| `/api/sessions` | POST | 建立新 session |
| `/api/sessions/{id}` | GET | 取得 session 內容 |
| `/api/sessions/{id}` | DELETE | 刪除 session |

### 2. 前端功能

- 聊天室介面（類似 CLI 的對話體驗）
- 即時串流顯示 LLM 回應（SSE）
- 對話歷史檢視
- Session 切換與管理

### 3. 技術堆疊

- FastAPI
- Uvicorn (ASGI 伺服器)
- Jinja2 (HTML 模板)
- 原有的 Code5Agent 核心（MockClient）

## 檔案異動

### 新增檔案

- `src/code5/web.py` - Web 啟動入口
- `src/code5/web/__init__.py` - Web module init
- `src/code5/web/app.py` - FastAPI 應用、SessionStore
- `src/code5/web/routes.py` - API 路由
- `src/code5/web/templates/index.html` - 聊天室頁面
- `tests/test_web.py` - Web 測試（含單元、API、E2E）

### 修改檔案

- `pyproject.toml` - 新增 fastapi, uvicorn, jinja2 依賴

## 啟動方式

```bash
# 方式1: 使用 Python
python -m code5.web

# 方式2: 使用 Uvicorn
uvicorn code5.web:app --reload

# 方式3: 使用 entry point
python -m code5.web
```

預設伺服器: http://localhost:8000

## 行為變更

1. 新增多了一個 web 介面（與 CLI 分開）
2. Web 使用獨立的 in-memory SessionStore（與 CLI 的 SQLite session 分開）
3. Web 預設使用 MockClient（可擴展為真實 LLM）
