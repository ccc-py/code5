## 專案概述

Code5 是一個類似 OpenCode 的開源 AI Coding Agent，使用 NVIDIA NIM 服務作為 LLM 後端。

### 主要功能

- **AI 對話式編碼輔助** - 使用自然語言與 AI 互動
- **Shell 命令執行** - 自動執行 shell 命令
- **安全審查** - 防止執行危險命令（rm -rf、dd 等）
- **對話記憶** - 滾動歷史 + 關鍵資訊提取
- **多 Session 支援** - 支援多個獨立對話
- **Mock 模式** - 測試無需呼叫真實 LLM

## 核心模組

### 1. agent.py - Code5Agent
主要代理類別，協調 LLM、工具執行、記憶體和安全審查。

### 2. client.py - LLM 客戶端
- `NVIDIAClient`: 呼叫 NVIDIA NIM API
- `MockClient`: 測試用，回傳預設回應
- `create_client()`: 工廠函數，根據配置建立客戶端

### 3. memory.py - 記憶體管理
- `ConversationMemory`: 滾動對話歷史
- `KeyInfoMemory`: 長期關鍵資訊
- `MemoryManager`: 組合管理

### 4. tools.py - 工具執行
- `ShellTool`: 安全 shell 執行
- `FileTool`: 檔案讀寫
- `ToolExecutor`: 組合執行器

### 5. reviewer.py - 安全審查
- `CommandReviewer`: 審查危險命令
- `MockReviewer`: 測試用 mock
- 危險模式偵測：rm -rf、dd、mkfs、curl|sh 等

### 6. session.py - Session 管理
- `Session`: 單一對話 session
- `SessionManager`: 多 session 持久化管理

## 使用範例

### Mock 模式（測試用）
```python
from code5 import Code5Agent, MockClient

agent = Code5Agent(client=MockClient())
result = await agent.run("Hello!")
```

### NVIDIA NIM 模式
```python
from code5 import Code5Agent, Config
from code5.client import NVIDIAClient

config = Config(api_key="nvapi-xxx")
agent = Code5Agent(client=NVIDIAClient(config))
result = await agent.run("Help me write a function")
```

### CLI 使用
```bash
# 互動模式
code5

# 單次執行
code5 "幫我寫一個 hello.py"

# 使用 mock
code5 --use-mock "Hello"
```

## 環境變數

- `NVIDIA_API_KEY`: NVIDIA NIM API key
- `NVIDIA_MODEL`: 模型名稱（預設：minimaxai/minimax-m2.7）
- `NVIDIA_BASE_URL`: API 端點
- `CODE5_USE_MOCK`: 設為 `true` 使用 mock 模式
