# Code5 v0.3 功能說明

## 版本資訊

- 版本: 0.3
- 日期: 2026-05-05
- 主要更新: SQLite 儲存、Session 管理、對話指令

## 安裝

```bash
pip install -e .
# 或
pip install -e ".[dev]"
```

## 使用方式

### 啟動對話

```bash
# 需要指定 session 名稱 (-n 或 --name)
code5 run -n myproject

# 單次執行
code5 run -n myproject "Hello"

# Mock 測試
code5 run -n myproject --use-mock
```

### Session 管理指令

```bash
# outside of conversation
code5 session list              # 列出所有 session
code5 session new <name>        # 建立新 session 提示
code5 session attach <name>    # 檢查 session 是否存在
```

### 對話中指令

| 指令 | 功能 |
|------|------|
| `/help` | 顯示說明 |
| `/history` | 顯示所有使用者提問（只限目前 session） |
| `/log` | 顯示完整對話記錄（只限目前 session） |
| `/shell <cmd>` | 直接執行 shell 命令 |
| `/session list` | 列出所有 session |
| `/session now` | 顯示目前 session 名稱 |
| `/session new <name>` | 切換到新 session |
| `/session attach <name>` | 切換到其他 session |
| `/exit` | 結束對話 |

### 其他指令

```bash
code5 doctor  # 檢查設定
```

## 架構

```
src/code5/
├── __main__.py    # CLI 入口
├── agent.py       # Code5Agent 主類別
├── client.py      # LLM 客戶端
├── config.py      # 設定管理
├── db.py          # SQLite 資料庫
├── memory.py       # 對話記憶體
├── prompts.py     # System prompts
├── reviewer.py    # 安全審查
├── session.py     # Session 管理
└── tools.py       # Shell/File 工具
```

## 資料儲存

- **SQLite**: `~/.code5/code5.db`
- **Sessions**: 透過 session 名稱區分
- 對話記錄持久化儲存

## 環境變數

- `NVIDIA_API_KEY` - NVIDIA NIM API key
- `CODE5_USE_MOCK=true` - 使用 mock client

## 與 LLM 的溝通會印出完整過程

執行時會印出：
- `[LLM] 請求:` - 送給 LLM 的 prompt
- `[LLM] 回應:` - LLM 的回應
- `[Shell] 執行命令:` - 要執行的命令
- `[Shell] 輸出:` - 命令執行結果
- `[LLM] 下一步:` - 繼續對話時的 prompt
